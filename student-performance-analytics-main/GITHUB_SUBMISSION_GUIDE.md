# GitHub Submission Guide

## Repository Name

Recommended repository name:

`student-performance-analytics`

## Files to Upload

Upload these project files:

- `main.py`
- `functions.py`
- `students.csv`
- `README.md`
- `Project_Documentation.md`
- `requirements.txt`
- `.gitignore`

`student_analysis_output.csv` can also be kept as an example of the generated result.

## Recommended Git Commands

Open a terminal inside this project folder:

```bash
git init
git add .
git commit -m "Initial student performance analytics project"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with the repository URL created on GitHub.

## Final Check

Before submission, open the GitHub repository in a browser and confirm that:

- The main Python file is present.
- The dataset is present.
- `README.md` is present.
- Documentation is present.
- The project runs successfully.
- The repository URL is copied correctly for the EWB Google Form.
